Determines how to remove data from leaves. Does not focus on removing anywhere else unless needed.

We first traverse the tree recursively until we reach a leaf node. If the target key is in leaves erase it and update parent data.

If the node has less children then min\+Degree -\/ 1 we check if we can borrow from sibling data if not we merge.

Once leaf data is fixed if underflow occurs we propagate to the internal nodes (we check this by checking if their children is less then mindegree)

To deal with underflow of internal nodes we check if parents siblings have a child they can give or else merge children and parent data.

This cycle will occur within internal nodes until a merge does not occur.
