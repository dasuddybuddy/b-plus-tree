template<typename T>
void BPlusTree< T >::insert ( T key)

Generic insert function for B plus tree. Checks if a root exists if not creates one. If size of root keys violates limit factor 2 * minDegree - 1 we create a new root and call the split child helper function to deal with overflow. Call insertNonFull helper if no overflow.

Parameters
keythe value being inserted

Helper function for insert to deal with overflow. This function will promote leaf data to parent while keeping data in leaves.

Create an empty sibling and insert it into the parents children vector. Insert the middle child of the full vector into parent array. Assign second half of array to sibling and first half to child. If the child is not a leaf reassign child pointers, else link the child and sibling together since they are leaves.
